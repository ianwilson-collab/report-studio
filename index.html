Format Tips
Type these tags inside any text field (accomplishments, priorities, milestones, risks, the critical message) to format the report text:
  • <em>italic</em> → italic
  • <strong>bold</strong> or <b>bold</b> → bold
  • <u>underline</u> → underline
  • <i>italic</i> → italic (same as <em>)
Other HTML is shown as plain text, so it's safe to type freely.
