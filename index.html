Every field updates the preview instantly. When it looks right, click Download Report to get a clean HTML file (no editing controls) to send to leadership.
To revise a past report, use Import HTML to load a previously downloaded report back in, edit it, and rebuild.
You can also click any element in the live preview to jump straight to its section here.
Format Tips
Type these tags inside any text field (accomplishments, priorities, milestones, risks, the critical message) to format the report text:
  • <em>italic</em> → italic
  • <strong>bold</strong> or <b>bold</b> → bold
  • <u>underline</u> → underline
  • <i>italic</i> → italic (same as <em>)
Other HTML is shown as plain text, so it's safe to type freely.
