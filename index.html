Format Tips
Format text in any of these fields — the leadership message and any accomplishment, priority, milestone, or risk — by typing tags, or by selecting text and pressing a shortcut:
  • <b>bold</b> → bold  ·  or select text and press Ctrl+B (⌘B on Mac)
  • <i>italic</i> → italic  ·  or Ctrl+I
  • <u>underline</u> → underline  ·  or Ctrl+U
Tags can be combined — for example, bold italic. Other HTML is shown as plain text, so it's safe to type freely.
